## Проект

**Mileage Tracker** — приложение учёта пробега для водителя доставки.
Водитель записывает поездки (дата, адрес откуда, адрес куда, километраж), бухгалтерия получает отчёт за месяц/год.

Подробности проекта и дорожная карта — в `CLAUDE.md`, раздел «Текущий контекст проекта».

## Диагностика стартового уровня

### Подтверждённые знания

- `final` / `const`: понимает разницу между заморозкой ссылки и содержимого. Верно определил, что `list.add()` работает при `final`, а `const DateTime.now()` — ошибка компиляции.
- Базовый опыт Flutter: курсовой проект — карта воздушных тревог Украины в реальном времени.
- Мышление по данным: самостоятельно отделил хранимое поле (дата) от вычисляемого значения (количество поездок). Сильный момент.

## Пройденные темы

- Понятие MVP: минимально жизнеспособный продукт, полный цикл работы в простейшем виде.
- Проектирование модели данных под будущие запросы к ней (отчёт за месяц → нужно поле даты).
- Решение о типе проекта: однопользовательское приложение без бэкенда как стартовая точка.
- Работа с Git-репозиторием самого Flutter SDK: обновление, разбор «local changes», принцип «SDK руками не правим».
- **Занятие 1:** классы, `final`-поля, named parameters, `required`, `const`-конструктор, nullable vs non-nullable.
- Выбор типа по смыслу данных, а не по отображению (`DateTime` вместо `String` для даты).
- `DateTime`: `==` сравнивает момент времени (до микросекунды), а не день — проверено экспериментом.
- Поиск API через автодополнение IDE и api.flutter.dev (getter'ы `DateTime` для года/месяца/дня).
- Git: `init`, `add` по файлам, `diff --staged`, `restore`, Conventional Commits (`chore:`, `feat:`), выход из пейджера `less` клавишей `q`.
- `pubspec.yaml` (допустимые версии) vs `pubspec.lock` (зафиксированные версии) — зачем коммитить lock в приложении.
- Принцип: в коммит не попадает изменение, которое не можешь объяснить.

## Повторяющиеся ошибки / наблюдения

- Склонность выбирать тип по внешнему виду данных (`String` для даты). Следить при выборе типов дальше.
- Отвечает «не знаю» вместо того, чтобы поискать в документации/IDE; при угадывании ошибается (`date` вместо `day`). Тренировать самостоятельный поиск API.
- Недооценивает будущие требования («в отчёте не надо сравнивать/плюсовать»), хотя отчёт по месяцу требует фильтрации и суммы. Возвращать к требованиям из `CLAUDE.md`.
- Аргументы уровня «так понятнее» — требовать технического обоснования.
